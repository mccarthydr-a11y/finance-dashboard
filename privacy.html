Privacy policy

Finance Dashboard · Last updated November 2, 2026

Finance Dashboard is a private, single-user personal finance tool that runs on its owner's own Mac. Its only user is its owner. This policy describes what it does with Google account data.

What it accesses

With the owner's consent, it uses Google's read-only Gmail permission (https://www.googleapis.com/auth/gmail.readonly) to read:

  • transaction alert emails from the owner's own credit card issuers: the amount, merchant, date and card shown in the alert; and
  • only the sender and authentication headers of "statement available" notices from the owner's own banks and retirement plan.

It does not read other messages, contacts or attachments, and it never sends, deletes, labels or changes email.

Where the data goes

Data read from Gmail is stored only in a local database on the owner's Mac, as a record of the owner's own transactions. The Gmail sign-in is stored in the Mac's Keychain. The tool has no server. It does not send Gmail data to anyone, does not sell or share it, does not use it for advertising, and does not use it to train AI or machine-learning models. The only network requests involving Gmail are to Google's own Gmail API.

Google API Services User Data Policy

Finance Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Imported transactions are kept on the owner's Mac for as long as the owner keeps them. Access can be revoked at any time at myaccount.google.com/permissions; the tool then stops reading Gmail. Deleting the tool's data folder on the Mac removes everything it stored.
