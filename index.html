Finance Dashboard

Finance Dashboard is a private, single-user personal finance tool. It runs only on its owner's own Mac and shows that person's account balances, transactions and statements. It is not offered to the public, and no one else can sign in to it.

How it uses Google

With the owner's permission, Finance Dashboard uses Google's read-only Gmail access (gmail.readonly) to look for:

  • purchase and payment alert emails from the owner's own credit card issuers, so new card transactions appear without waiting for a statement; and
  • "statement available" notices from the owner's own banks and retirement plan, so the tool knows when to download a new statement from that bank's website. For these notices it reads only the sender and the email's authentication results.

It never sends, deletes, labels or changes email, and it reads no other messages. Everything it reads stays on the owner's Mac. See the privacy policy.
